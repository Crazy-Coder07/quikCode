Online Compiler for HTML, CSS, and JavaScript
Overview

This is a web-based compiler that allows users to write and execute HTML, CSS, and JavaScript code directly from their browser. The online compiler provides an interactive environment for front-end development without the need for any external tools or setup.
Features

    Real-time Preview: Displays live output as you type your HTML, CSS, and JavaScript code.
    Separate Code Editors: Dedicated panels for writing HTML, CSS, and JavaScript.
    Responsive Design: Works on various screen sizes for optimal user experience.
    Customizable Layout: Ability to resize code panels as per preference.
    Error Handling: Highlights syntax errors in the code.

Technologies Used

    Frontend: HTML5, CSS3, JavaScript (ES6+), React, react-mirror
    CodeMirror/Monaco Editor: For syntax highlighting and code formatting.
    Live Preview: Embeds the generated code output into an iframe.

Installation & Setup

No installation is needed! Simply clone the repository and run the project locally.
Steps to Run Locally

    Clone the repository

    git clone https://github.com/Crazy-Coder07/quikCode.git

    Open the index.html file in your preferred browser.
    Start coding in the provided editor panels for HTML, CSS, and JavaScript.

How to Use

    Write Code: Enter your HTML, CSS, and JavaScript code in their respective editors.
    See Output: As you type, the result will automatically be rendered in the output preview section.
    Debug: Check the console in the developer tools for any JavaScript errors.
